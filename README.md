# Illia Ivashchenko — Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript. It presents my background, experience, skills, projects, and resume.

## Features

- Responsive layout for desktop and mobile
- Navigation between About, Work, Projects, and Contact sections
- Resume link
- GitHub, LinkedIn, and email links

## Built with

- HTML
- CSS
- JavaScript

## Run locally

Clone the repository, then open `index.html` in a browser.

## Project files

- `index.html` — page content and structure
- `styles.css` — styling and responsive layout
- `script.js` — navigation interactions
- `resume.pdf` — resume document

## Deployment

This site can be published with GitHub Pages from the repository’s `main` branch.
